# TripTracker (Compose)

## Preview the UI

Open the project in Android Studio and use the Compose Preview panel to render the screens:

1. Open `app/src/main/java/com/example/triptracker/MainActivity.kt`.
2. In the **Preview** tool window, build and refresh previews for:
   - `OverviewScreenPreview`
   - `RewardsScreenPreview`
   - `InsightsScreenPreview`

These previews render the main trip planner, rewards/referrals, and live insights screens without running a device or emulator.
